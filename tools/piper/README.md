Local text-to-speech for narration, run as a separate program.

## What it is

Local text-to-speech for narration — text in, spoken audio out, on the
person's own machine. Its original home, rhasspy/piper, has moved; the maintained one,
OHF-Voice/piper1-gpl, is the one listed here.

## The package

`source github.com/OHF-Voice/piper1-gpl; licence GPL-3.0-or-later. Latest
release v1.8.0; the repository's main branch stood at commit 6565650 on 2026-11-13.` Its
original home, rhasspy/piper (MIT, last release v1.2.0), is named as left behind for this
maintained one.

## What it reads

The text to be spoken, and local voice models.

## What it never does here

Because it is GPL-3.0-or-later it is only ever called as a
separate program; none of its code goes into the commons or a Recipe; nothing leaves the
machine.

## Scope

Local text-to-speech for narration.

The Marketing Delegate's video work, for narration. Not built or used yet.
